# Changelog

All notable changes to the CherryCooldowns plugin will be documented in this file.

## [1.0.1] - 2026-11-08

### Added
- **Action Bar Feedback System**: Added a repeating task (`actionBarCooldownsRun`) to display remaining cooldown time directly in the action bar when holding an item on cooldown.
- **Action Bar Configuration**: Added `actionbar_format` setting in `config.yml` supporting custom color codes (`&`) and the `%cooldown%` placeholder.

### Changed
- Updated Maven dependency version and JAR build outputs to `1.0.1`.
- Improved configuration structure and updated default `config.yml`.
