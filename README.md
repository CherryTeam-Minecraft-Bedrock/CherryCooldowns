# CherryCooldowns

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Java 17](https://img.shields.io/badge/Java-17-orange)](pom.xml)
[![Version](https://img.shields.io/badge/version-1.0.0-informational)](pom.xml)

CherryCooldowns is a lightweight item cooldown management plugin and developer API. It allows server administrators to control item consumption and right-click interaction delays on Minecraft servers.

## Documentation

* [Nukkit Documentation](https://github.com/CherryTeam-Minecraft-Bedrock/CherryCooldowns/blob/main/nukkit/README.md) - Detailed guide for Nukkit server setup, permissions, configuration, and API usage.
